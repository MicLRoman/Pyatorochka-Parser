# Парсер Пятёрочки → товары для нейросети

Вытаскивает товары (название, описание, БЖУ, цена, вес) и складывает в `products.json`,
который можно отдать нейросети с просьбой составить план: что купить и что приготовить.

## Установка (один раз)

```powershell
pip install pyaterochka_api
```

Браузер берётся из уже установленного Google Chrome (через Playwright, который ставится
вместе с библиотекой). Camoufox НЕ нужен.

---

## ГЛАВНЫЙ способ — через твой Chrome (режим --cdp)

Сайт 5ka.ru защищён антиботом **ServicePipe**: он ловит браузер, запущенный «роботом»
(Playwright/Selenium), и выдаёт неубиваемую капчу. Поэтому самый надёжный путь —
подключиться к **твоему настоящему Chrome**, где проверка проходит по-человечески.

**Шаг 1.** Открой Chrome с отладкой (скрипт сделает сам):
```powershell
py.exe parser5ka.py --open-chrome
```
Откроется отдельное окно Chrome на 5ka.ru.

**Шаг 2.** В этом окне **пройди проверку ServicePipe руками** (капча «разверни картинку»),
дождись, пока загрузится нормальная витрина Пятёрочки. **Окно не закрывай.**

**Шаг 3.** В терминале запусти парсер с подключением к этому Chrome:
```powershell
# разведка одного товара (проверить, что всё работает и где БЖУ):
py.exe parser5ka.py --probe 3551126 --cdp 9222

# собрать товары:
py.exe parser5ka.py --cdp 9222 --max-products 40
```

Результат → `products.json`. Его и отдавай нейросети.

> Профиль этого Chrome сохраняется в `%USERPROFILE%\chrome-5ka`, поэтому в следующий раз
> проверку, скорее всего, проходить не придётся — куки запомнятся.

## Команды

**Список категорий** (узнать их id):
```powershell
py.exe parser5ka.py --list-categories --cdp 9222
```

**Разведка товара** (PLU — число из ссылки товара на 5ka.ru):
```powershell
py.exe parser5ka.py --probe 3551126 --cdp 9222
```
Создаёт `sample_product.json` — сырой JSON карточки (видно, где лежит БЖУ).

**Сбор товаров:**
```powershell
# всё подряд, по 40 товаров с категории:
py.exe parser5ka.py --cdp 9222

# только выбранные категории, по 100 товаров:
py.exe parser5ka.py --cdp 9222 --categories 73C2261,73C2271 --max-products 100
```

## Полезные флаги
- `--cdp 9222` — подключиться к твоему Chrome (см. выше). **Нужен почти всегда.**
- `--max-products N` — сколько товаров брать из каждой категории
- `--max-categories N` — ограничить число категорий
- `--categories id1,id2` — только эти категории
- `--delay 0.4` — пауза между товарами в секундах
- `--checkip` — диагностика: с какого IP выходит браузер

## Если БЖУ не находится
Скрипт ищет БЖУ автоматически по словам «белки/жиры/углеводы/protein/fat/carb»
в карточке товара. Если нашлось мало — открой `sample_product.json`, посмотри,
как реально называются поля, и пришли мне — поправлю извлечение под точные ключи.
